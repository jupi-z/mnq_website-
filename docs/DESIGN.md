# Design system — Direction

## Principes
Institutionnel, sobre, géométrique, sans ombres décoratives ni empilement de cartes. Hiérarchie éditoriale forte, espaces blancs importants, composants accessibles, mouvement discret. La marque papillon et les logos officiels restent intacts.

## Palette de départ (tokens UI, pas remplacement de la charte du logo)
- Encre : #111318
- Papier : #FFFFFF
- Arrière-plan secondaire : #F5F5F2
- Orange signal : #F15A24
- Rouge signal : #D82332
- Vert secondaire : #2C8D55
- Jaune secondaire : #F6B900

## Composants
Navigation principale, hero institutionnel, sections de secteurs, fiche d'activité avec statut éditorial, témoignage uniquement autorisé, espace contact, pied de page. Préférence motion réduite respectée.

## Assets
Trois images sources officielles remises par la direction : logo horizontal, logo complet, icône papillon. Avant déploiement intégrer des versions optimisées du contenu original aux chemins documentés dans `public/brand/README.md`. Aucun logo recréé ni altéré, aucun dessin génératif substitutif.
